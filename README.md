# 鳩市長の街づくり — Pigeon Sandbox

一羽の鳩が市長となり、人と鳩の両方が暮らしやすい街をつくる、穏やかな箱庭ゲームです。駅前広場から始めて施設を建て、鳩たちの食事・水浴び・散歩・休憩・仲間との交流を眺めながら街を育てます。

**現在のメイン版はUnity製のMacアプリです。** [GitHub Releases](https://github.com/Maviator7/pigeon_sandbox/releases)からMac試遊版をダウンロードできます。macOS 12以降、Apple SiliconとIntelに対応しています。Developer ID署名・公証はまだ行っていません。

## 遊び方

左側で施設を選び、街の空きマスをクリックして建設します。パン屋・噴水・集合住宅・街路樹・広場・時計台・オープンカフェ・花壇の公園の8種類があります。例えば、パン屋の近くに広場を置くと人の混雑を和らげ、鳩の集まる場所にもなります。施設の改良・移設・撤去と、街の予算を使った土地拡張もできます。

街には名前・性格・羽色の違う鳩が住みます。施設の配置によって新しい羽色の鳩が訪れ、図鑑に記録されます。鳩同士は一緒に散歩・休憩・水浴びをして仲良しになります。朝・昼・夕方に加え、ゲーム内の15日（約30分）ごとに春夏秋冬が巡ります。木や花壇、空の色、鳩が好んで向かう場所が変わり、鳩本人から小さなお願いが届くこともあります。

3日ごとに「街の催し」を開けます。パン屋の朝市、水辺の午後、時計台の夕暮れから選び、会場となる施設を近くに置いて開催してください。また、春は花見、夏は水辺の集い、秋は秋の市、冬は冬の観察会が自動で始まります。季節に合う会場を整え、鳩や人の実際の行動を見守ると、参加した鳩の名前入り絵はがきが届きます。季節の催しを逃しても翌年に再挑戦できます。通常の催しとお願いに期限や失敗のペナルティはありません。鳩に危害が加わるイベントはありません。

| 操作 | 内容 |
| --- | --- |
| 左クリック | 空きマスに建設、施設を選択 |
| 左ドラッグ | マップを移動 |
| 右ドラッグ | 視点を回転 |
| マウスホイール／マップ上の＋・− | 拡大・縮小 |
| 街全体 | マップ全体を見る視点に戻す |
| 鳩図鑑の名前 | その鳩にフォーカスして追従 |
| 名前の横の「改名」 | 鳩の名前を変更 |
| Space／一時停止 | 時間を停止・再開 |

画面右の「お願い」で鳩と街の住民からの依頼、「鳩図鑑」で個体と羽色、「条例」で街の方針、「催し」で開催条件・進行状況・絵はがきを確認できます。ゲームは30秒ごとと終了時に自動保存され、「街を保存」から手動でも保存できます。

## Macアプリの更新

新しいバージョンはZIPを展開してアプリを入れ替えます。セーブデータはアプリ本体の外、`~/Library/Application Support/PigeonSandbox/Pigeon Sandbox/mayor-town.json` に保存されます。更新前にこのファイルをコピーしておくと安心です。自動更新機能はありません。

## Unityで開発する

Unity **6000.3.11f1**で [`unity/PigeonSandbox`](unity/PigeonSandbox) を開き、`Assets/Scenes/Park.unity` を再生します。MacアプリはEditorメニュー **Pigeon Sandbox > Build Mac app** で生成できます。詳しい手順と検証方法は[Unity版README](unity/PigeonSandbox/README.md)にあります。

```bash
python3 unity/PigeonSandbox/Tests/verify.py      # C#のコンパイルとテスト
python3 unity/PigeonSandbox/Tools/format.py      # C#の整形
```

最大マップでの性能を測るベンチマークと計測オーバーレイ（F3）もあります。使い方は[Unity版README](unity/PigeonSandbox/README.md#パフォーマンス計測)を参照してください。

`unity/PigeonSandbox/Assets/PigeonSandbox/Core` はUnityの描画に依存しない街・鳩の行動と保存、`Runtime` は3Dモデル・入力・画面表示です。鳩や建物は外部モデルがなくても表示できる簡略モデルです。スマートフォン版は将来対応を想定していますが、現在配布しているのはMac版です。

## 旧Web試作（参考資料）

リポジトリ直下の `src/`・`tests/`・`public/` は、初期のブラウザ用3D鳩シミュレーターです。現在の街づくりゲームとは内容が異なり、**参考資料として残しているだけで保守していません**。依存パッケージの更新や不具合修正も行いません。試作をローカルで動かす場合は、Node.js 22以降で `npm install`、`npm run dev` を使用します（テストは `npm test`）。

利用したNoto Sans JPのライセンスは、配布ZIPに同梱しています。
