# 3D鳩モデル差し替えガイド

## まず置くだけで試す

1. GLB 2.0形式で、テクスチャを埋め込んだ `pigeon.glb` を用意する。
2. `public/models/pigeon.glb` に配置する。
3. ブラウザを再読み込みする（読込結果をメモリにキャッシュしているため、ファイルを置いた後は再読み込みが必要）。
4. 鳩をクリックし、観察パネル下部が「GLB モデル」になったことを確認する。

壊れたGLBや未配置では「手続きモデル」を表示します。元のGLBの寸法を測り、高さ1.67単位に正規化し、水平中心と地面を揃えます。

## 座標と調整箇所

`src/components/Pigeon/PigeonModel.tsx` の `MODEL_CONFIG`：

```ts
export const MODEL_CONFIG = {
  url: '/models/pigeon.glb',
  height: 1.67,
  rotationY: 0,
};
```

- Yが上、+Zが鳩の正面。反対を向くモデルは `rotationY: Math.PI` にする。
- 高さが不自然なら `height` を変更する。
- 原点は足元の中央。モデル自動正規化後の位置は `LoadedModel` の `normalized.position` で調整可能。
- 選択用の箱、頭上ラベル、選択リングは `Pigeon.tsx` で調整する。寸法を大幅に変えた場合はこちらも揃える。
- クリップは原点から移動しないin-placeにする。移動はcontroller側が担当し、root motionは取り込みません。
- Draco/KTX2圧縮用デコーダは未設定です。まず非圧縮のGLBで確認してください。外部参照テクスチャがある場合は同じ `/models/` 以下へ置きます。

## AnimationClip

| 状態                       | 優先するクリップ |
| -------------------------- | ---------------- |
| IDLE                       | Idle             |
| WALK                       | Walk             |
| RUN                        | Run              |
| PECK                       | Peck             |
| EAT                        | Eat              |
| FLY / PANIC / HELD         | Fly              |
| LAND                       | Land             |
| LOOK_AROUND / LOOK_AT_FOOD | LookAround       |

大文字・小文字は区別しません。名前が違う場合は `CLIPS` マッピングを変更するか、制作ツールでクリップ名を合わせます。動きの速度はシミュレーションの再生速度に従います。

## クリップがない場合

以下のGroupまたはBone名を持つモデルでは、`PigeonAnimation.ts` の手続きアニメーションを使用します。

```text
Body
  Neck
    Head
  WingL
  WingR
  Tail
LegL
LegR
```

回転の基点は翼の付け根、脚の付け根、首の根元に置きます。基準姿勢からの差分を加えます。クリップのない状態だけ手続きアニメーションになります。

制作したリグは軸・長さが異なるため、`captureRig()` の対応名と `animateRig()` の軸・振幅をモデルに合わせて調整してください。名前付きパーツがない一体型モデルでは全身の呼吸とついばみ時の傾きにフォールバックします。独立した首振りや羽ばたきを行うにはパーツ分割・リギング、またはAnimationClipが必要です。

## 差し替え後の確認

- 待機、歩行、ついばみ、飛行、着地それぞれを確認する。
- パンくずを置き、くちばしが地面へ向くことを確認する。
- 持ち上げて離し、足元が地面に一致することを確認する。
- 追尾と通常カメラの両方で目・羽・首の見え方を確認する。
- モデルを一時的に移動して、仮モデルへのフォールバックも確認する。

現在の手続きモデルは、添付写真の灰色の胴体、緑紫の首、翼帯、尾、足色を参考にしています。写真から自動復元された3Dモデルではありません。
