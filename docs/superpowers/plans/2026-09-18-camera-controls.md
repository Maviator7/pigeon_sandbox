# 鳩フォーカスとマップ操作

承認済み設計: 図鑑の名前から滑らかにフォーカス・追従。左ドラッグで移動して追従解除。ホイールと＋／−でズーム。街全体ボタンで復帰。右ドラッグ回転を維持。

## 実装手順
- SandboxApp.cs にカメラ注視点、追従対象、ドラッグ状態を追加。シミュレーションは変更しない。
- マウスとタッチは押下開始位置と移動履歴を保持し、UI上で開始した操作とドラッグ終了を建築クリックにしない。
- 図鑑の名前を既存Buttonで表示。高さは文字から計算。
- マップ上端に44px高の操作ボタンと追従状態を配置。入力判定から除外。
- Unity C#検証、Macビルド、実画面操作でフォーカス、ドラッグ、ズーム、復帰を確認。
