# Pigeon Mayor Implementation Plan

**Goal:** Unity Mac版を、鳩市長が人と鳩の街を育てる広場経営ゲームに変更。
**Architecture:** Unity非依存のTownSimulationで予算、施設、配置効果、住民、お願いを管理。TownWorldは施設と住民を描画し、SandboxAppは日本語UIとグリッド配置を担当する。
**Tech Stack:** Unity 6000.3.11f1、C#、既存Macビルド。

ユーザー指定の初回試作範囲を採用。施設6種類（ベーカリー、噴水、集合住宅、街路樹、広場、時計台）、性格4種類（食いしん坊、水浴び好き、目立ちたがり、臆病）。市長と名前つき鳩、人間の来訪・購買、収支、食料供給、幸福度、満足度、混雑、清掃、お願い3件。条件つき白い鳩の来訪と図鑑ヒント。無料の移設と一部払い戻しで復旧可能。基本条例は巣箱・水浴び優先・カフェ支援を実装。猫や危害イベントは含めない。

- [ ] Core/TownSimulation.cs: 配置・予算・自律行動・お願い・条件つき来訪、独立C#テスト。
- [ ] Runtime/TownWorld.cs: 6施設と滑らかな複数鳩、人間、配置プレビュー。
- [ ] Runtime/SandboxApp.cs: 日本語経営UI、建設/移設/改良/撤去、観察、条例、図鑑、速度、保存。
- [ ] Editor/BuildMac.cs: 新仕様の検証とMacビルド。
- [ ] 実画面で配置、予算、動く鳩、施設移設、お願いと図鑑を確認。
- [ ] README/AGENTS更新。Web版は従来版として保持。

道路網・選挙・天候・大規模産業・地区拡張は今回の広場試作には含めない。スマホ実機対応は後続。
