# Unity Mac Implementation Plan

**Goal:** Web版と並行してMacで遊べる平和な鳩観察アプリを作る。
**Architecture:** Unity非依存のC#シミュレーションをUnityの描画・入力から分離。滑らかな仮モデルと公園をコード生成し、外部モデルなしで動作する。マウスとタッチは同じ操作入口へ渡す。
**Tech Stack:** インストール済みUnity 6000.3.11f1、C#、標準レンダラー。

- [x] Core/PigeonSimulation.cs: 注入乱数、餌の探索・摂食、散歩、飛行、着地、休憩、呼びかけ。
- [x] Runtime/PigeonWorld.cs: 滑らかな鳩、公園、羽ばたき・首振り・歩行を生成。
- [x] Runtime/SandboxApp.cs: カメラ、クリック/タッチ餌やり、観察UI、リセット。
- [x] Editor/BuildMac.cs: 起動シーン作成、行動検証、Macアプリのビルド処理。
- [x] Unityバッチモードで検証とビルド。アプリ起動とスクリーンショット確認。
- [x] README/AGENTS/.gitignore更新。生成物はGit対象外。

2026-09-15: 全C#のコンパイル・独立AIテスト成功。ライセンス有効化後、Unity内行動検証・Macビルド・実アプリの描画と摂食結果を確認済み。

初版はMac向け。スマホ用の操作入口は用意するが、iOS/Androidのビルド・実機検証は将来対応。捕食や危害イベントは含めない。
