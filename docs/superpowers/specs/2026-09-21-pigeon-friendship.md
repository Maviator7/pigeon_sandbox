# 鳩同士の仲良し関係

承認された体験：自然に育つ仲良し関係、同じ相手と散歩・ベンチで休憩・水浴び、再会のクルクル、図鑑に「よく一緒にいる」。世話のノルマ・関係の減衰・鳩への危害は追加しない。

TownSocial の既存ペア行動を拡張する。関係は安定IDのペアと共有時間で表し、実際に並んで休む間だけ加算。累計12秒で仲良し。上限120秒。最も親しい相手を図鑑に表示し、改名は即時反映。既存の食事・飛行・単独水浴びを中断しない。近くの仲良しを優先しつつ新しい相手とも交流できる。

広場では同じベンチの左右へ移動し、小さく上がって並んで休む。噴水では縁の左右に並んで水浴び。公園の既存の羽繕い・日向ぼっこは維持。一施設一組、相互ID、20秒以上の休憩間隔、施設移設・撤去時の解散を維持。仲良しとの再会時に35%で1.4秒の一回転を行い、散歩へ移る。回転中は移動せず通常の食後ダンスと二重実行しない。

関係だけ保存し、進行中の行動はロード時に初期化。旧セーブは関係なしで開始。関係データを復元する前に自己参照・不明ID・重複ペア・非有限/負の時間を拒否し、失敗時は現在の街を変更しない。保存は深いコピー。
