# 鳩市長の街づくり v0.1.0 — Mac試遊版

鳩の市長になって、人と鳩が暮らす小さな街を育てる箱庭ゲームです。

## ダウンロード

`PigeonSandbox-v0.1.0-macOS.zip` をダウンロードしてください。GitHubが自動表示する `Source code` はゲーム本体ではありません。

- macOS 12以降。Apple Silicon・Intel両対応。
- AppleのDeveloper ID署名・公証は未対応です。macOSが起動を制限する場合があります。
- 開発中の試遊版です。別機種での動作、日本語入力・タッチ入力の実機検証は未完了です。

## 遊べること

- パン屋・噴水・住宅・街路樹・広場・時計台・カフェ・公園の建設と改良
- 街の予算による土地拡張（最大17×17マス）
- 名前と性格を持つ鳩の観察、名前変更、個体へのカメラ追従
- 食事・水浴び・羽繕い・日向ぼっこ・ごきげんクルクル
- 来訪者の買い物、お願い、条例、白い鳩との出会い

## はじめ方・操作

ZIPを展開し、`Pigeon Sandbox.app` をApplicationsなどへコピーして起動します。

- 左の施設一覧をスクロールして選び、空いているマスをクリックすると建設。
- 左ドラッグでマップ移動、右ドラッグで回転、ホイールまたは＋／−でズーム。
- 「街全体」で視点を戻します。
- 鳩図鑑の名前をクリックすると追従。「名前を変更」で名前を編集。
- 「街を保存」で保存。30秒ごとと終了時にも自動保存。

## 更新とセーブデータ

自動更新機能はありません。ゲームを保存・終了してから、新しいバージョンのZIPを展開し、アプリを入れ替えてください。

セーブファイルはアプリ本体とは別の `~/Library/Application Support/PigeonSandbox/Pigeon Sandbox/mayor-town.json` に保存します。更新前にコピーを取ると安心です。アプリ本体を入れ替えても、このファイルは削除しません。

不具合はリポジトリのIssuesへ、macOSのバージョンと操作手順を添えてお知らせください。
