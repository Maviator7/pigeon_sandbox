# Pigeon Sandbox — Unity / Mac

Web版と並行して開発するMac向け初版。Unity 6000.3.11f1を使用。

## 開く

1. Unity Hubにこのディレクトリをプロジェクトとして追加。
2. Editorライセンスを有効にして開く。
3. 初回に `Assets/Scenes/Park.unity` が自動生成される。Playで開始。
4. シーンを再生成する場合は `Pigeon Sandbox > Create observation scene`。

## Macアプリ生成

`Pigeon Sandbox > Build Mac app` でAI検証後にビルドする。
出力は `Builds/Mac/Pigeon Sandbox.app`。BuildsはGit対象外。

```sh
/Applications/Unity/Hub/Editor/6000.3.11f1/Unity.app/Contents/MacOS/Unity \
  -batchmode -quit -projectPath "$PWD/unity/PigeonSandbox" \
  -executeMethod PigeonSandbox.Editor.BuildMac.Build \
  -logFile /tmp/pigeon-unity-build.log
```

上のコマンドはリポジトリルートから実行する。

## 操作

- 左の施設を選び、街の空きマスをクリックして建設。施設には人間向けと鳩向けの両方の価値があります。
- 施設をクリックすると詳細を表示。移設は無料、改良はレベル3まで、撤去は投資額の70%を返金します。
- 「お願い」で住民の目標、「鳩図鑑」で名前・性格・行動、「条例」で街の方針を確認。
- 鳩図鑑の名前をクリックすると、その鳩へ寄って追従します。追従対象には名前と行動の目印が表示されます。左ドラッグ・「追従解除」・Esc・建築施設の選択で追従を解除します。
- 右ドラッグでカメラ回転、スクロールまたはマップ上端の＋／−でズーム。「街全体」で視点を戻します。Pause / Spaceで時間停止、速度で進行を早めます。
- 「街を保存」で保存。終了時にも自動保存し、Resetは現在未提供です（保存ファイルを削除すると初期状態に戻ります）。
- タッチ入力の入口も実装済み。1本指タップで建設・選択、ドラッグでマップ移動、2本指で移動・ズーム。

## 初版の内容と制限

駅前広場、8施設、4種類の性格を持つ名前つき鳩、来訪者の購買、街の収支、食料供給、鳩の幸福度、人間の満足度、混雑、清潔さ、お願い3件、条例3件、条件を満たした白い鳩の来訪、歩行・食事・水浴び・休憩・観光を実装。外部モデル・音素材は不要。鳩を追い払う、捕食、攻撃、負傷、死亡などの危害イベントはありません。

Unity非依存の `Core` を共通化し、将来のiOS/Android移植に備える。スマホ版のビルド、縦画面レイアウト、実機操作・性能検証は未実施。小画面向けUIは対応時に再調整する。

## 検証

`python3 unity/PigeonSandbox/Tests/verify.py` をリポジトリルートから実行。
Unity付属C#コンパイラでランタイムAPIを検証し、純粋AIの餌・呼びかけ・着地・境界・乱数再現性・容量制限、および街の建設・経済・性格ごとの目的地・お願い・希少個体・保存復元をテストする。

2026-09-15: C#コンパイルとAIテスト成功。ライセンス有効化後、Unity内の行動検証とMacビルドも成功。実アプリで鳩・公園・UIの描画、飛行・着地、餌表示と摂食回数3・慣れ53への変化を確認。実行ログに例外なし。スマホ実機検証は未実施。

カメラ操作の検証: Editorメニュー `Pigeon Sandbox > Verify camera controls`。実際のUnity Cameraで注視点、移動・飛行への追従、解除、建築への切替、パン、全体表示、UI入力除外を検証します。

鳩図鑑の「名前を変更」から、各個体の名前を1〜24文字で編集できます。「保存」で確定して街データも保存し、「キャンセル」で取り消します。同名の鳩も登録できます。入力中はマップ操作とゲームのキーボードショートカットを止め、日本語変換を優先します。

「ごきげんクルクル」: 幸福度65以上の街で、食事・水浴びの滞在を終えた鳩が35%の確率で約1.4秒の一回転を見せます。移動・飛行中には始めず、一時停止中は回転も止まります。終了後はいつもの行動へ戻ります。

土地拡張: 左パネル下部の「土地を広げる」から街の予算で購入します。9×9 → 11×11 → 13×13 → 15×15 → 17×17マス、料金は順に500 / 1,000 / 1,800 / 3,000円です。外周が1マスずつ増え、建物・鳩を残したまま建築可能な土地が増加します。購入時に自動保存し、「街全体」も拡張範囲に合わせます。以前のセーブは9×9の街として読み込めます。

追加施設: オープンカフェ（180円）は来訪者の購買と鳩の休憩・人との交流の場所です。2マス以内にパン屋があると食料供給と売上が増加します。花壇の公園（95円）は混雑を緩和し、鳩が羽繕い・日向ぼっこをします。2マス以内の住宅との組み合わせで混雑緩和と満足度への効果が増します。建築メニューはスクロールで全8種類を選べます。どちらも改良・移設・撤去・保存復元に対応します。

## 試遊版の公開・更新

GitHub ReleasesにバージョンごとのMacアプリZIPを配布します。自動更新機能はありません。更新時はゲームを保存・終了し、新しいZIPを展開してアプリを入れ替えます。セーブはアプリ外に保存するため、会社名・製品名・保存形式の互換性を維持します。

リリース時は `Editor/BuildMac.cs` の `ReleaseVersion` を更新し、`Tests/verify.py` とUnity内カメラ検証を実行してからMacビルドします。対応するコミットにバージョンタグを付け、アプリ・操作説明・フォントライセンスをZIPに同梱して公開します。公開済みZIPの差し替えではなく、新しいバージョンで公開してください。

鳩同士の交流: 近くの鳩がときどき2羽で公園・広場へ散歩し、少し間隔を空けて約7秒休憩します。公園では日向ぼっこ・羽繕いの仕草を見せます。図鑑と追従表示に相手の現在の名前を表示します。食事・水浴び・飛行・クルクルは中断しません。交流後は各自の行動に戻り、再び交流するまで間隔を空けます。既存セーブは引き継げますが、進行中の交流は読み込み時に解除して再開します。

### 羽色の図鑑
青灰・ごま模様・茶色・白黒まだら・白の5種類。図鑑には未発見のシルエットと環境ヒント、発見後には現在の個体名を表示します。パン屋に近い広場、パン屋に近いカフェ、街路樹に近い花壇の公園をそれぞれ45秒維持すると新しい羽色の仲間が訪れます（近接は2マス以内）。既存の白い鳩の条件は変わりません。住民は最大15羽となり、追加の羽色には専用枠があるため、既存住民を置き換えません。羽色と名前は保存され、従来のセーブも読み込めます。未発見の来訪待ち時間はロード時にリセットされます。模様は細かな凹凸を使わない簡略表現です。

### よく一緒にいる仲間
鳩が並んで休憩や水浴びをすると、相手との関係が自然に育ちます。何度か一緒に過ごすと図鑑に「よく一緒にいる：名前」が表示され、近くの仲良しを優先して誘います。相手が忙しいときは他の鳩とも交流できます。仲良しとの再会では、ときどき二羽でクルクル回ります。広場では同じベンチに、噴水では縁に並んで過ごします。関係に世話のノルマや減衰はなく、改名にも追従します。関係はセーブに残り、進行中の散歩などは再開時に初期化されます。旧セーブからもそのまま遊べます。

### 朝・昼・夕方
1日120秒の既存時計に合わせて、朝・昼・夕方が40秒ずつ巡ります。上部のDAY表示に時間帯を追加し、街の光と背景色は明るさを保ちながら滑らかに変化します。朝は食事場所、昼は噴水や公園、夕方は公園・木・住宅を選びやすくなります。性格の好みや進行中の食事・仲間との行動は維持します。一時停止中は時間と光も止まり、保存から同じ時間帯を再開します。夜はまだ実装していません。

### 鳩からの小さなお願い
「お願い」タブに、食いしん坊・水浴び好き・臆病な住民から一件ずつ届きます。パン屋近くの広場で仲良しと休憩、住宅近くの噴水で水浴び、静かな木陰の公園で休憩の3種類です。近接条件は2マス以内で、木陰の公園はパン屋・カフェ・時計台から離します。依頼した鳩が条件の場所を実際に2秒利用すると達成し、落ち着いたタイミングで感謝のクルクルをします。依頼主の名前を押すとフォーカスできます。期限・罰・金銭報酬はなく、達成状態と依頼主IDを保存します。旧セーブにも自動でお願いが加わります。
